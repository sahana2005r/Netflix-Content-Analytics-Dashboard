# Netflix Content Analytics Dashboard

## 📊 Project Overview

This project analyzes Netflix content using Microsoft Excel.

The project focuses on data cleaning, transformation, exploratory analysis,
Pivot Tables, KPI creation, and interactive dashboard development.

The final dashboard provides insights into Netflix movies and TV shows,
content trends, countries, ratings, genres, directors, and release years.

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Transformation
- Data Visualization
- Dashboard Design

---

## 📁 Project Structure

- RAW DATA – Original Netflix dataset
- CLEANED DATA – Cleaned and transformed dataset
- LOG – Data cleaning and transformation log
- PIVOT TABLES & INSIGHTS – Analytical questions and insights
- PIVOT ANALYSIS – Pivot Table calculations
- NETFLIX 1 – Main Netflix overview dashboard
- NETFLIX 2 – Content and trend analysis dashboard

---

## 🧹 Data Cleaning

The dataset was cleaned and transformed before analysis.

Major cleaning operations include:

- Removed the s prefix from show_id
- Handled missing values in director, cast, and country
- Created Month from date_added
- Created Year from date_added
- Renamed columns for better presentation
- Prepared the dataset for Pivot Table analysis
